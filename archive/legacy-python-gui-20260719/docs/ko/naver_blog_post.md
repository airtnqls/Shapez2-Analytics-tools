# Shapez2 Analyzer: 모든 도형을 맡기는 MAM 비밀 병기

Shapez 2라는 공장 게임을 플레이하다 보면, 한 단계씩 설비를 늘려 가며 도형을 맞춰 나가는 재미가 쏠쏠합니다. 그런데 공정이 점점 복잡해질수록 “이걸 그냥 하나의 거대한 MAM(make anything machine)으로 처리할 수 없을까?”라는 생각이 들죠. Shapez2 Analyzer는 바로 그 욕심을 현실로 만들어 주는 도우미입니다. 일일이 공장을 짓지 않고도, 어떤 도형이든 한 번에 설계·검증·시각화할 수 있게 도와주는 분석 툴입니다.

## 무엇을 위해 만들어졌나요?

Shapez2 Analyzer는 “도형 코드를 중심으로 게임 로직을 해부하자”는 목표로 제작됐습니다. PyQt6 기반 GUI를 실행하면, 도형 코드를 입력하거나 저장된 파일을 불러와 즉시 결과를 확인할 수 있습니다. 결과가 마음에 들지 않으면 곧바로 다른 조합을 적용해 보고, 최종적으로는 모든 공정을 하나의 MAM 설계도에 녹여 낼 수 있죠.

## 핵심 기능 한눈에

- 도형 시각화 & 실시간 시뮬레이션: 커터, 스태커, 페인터, 핀 푸셔 등 게임 속 기계를 버튼 한 번으로 실험해 보고, 결과를 그래픽으로 확인합니다. MAM 설계에 들어갈 세부 공정을 미리 조정하는 데 딱 좋습니다.
- 그래프 기반 프로세스 트리: process_tree_solver가 그려 주는 그래프를 통해 도형 제작 경로를 노드와 간선으로 파악할 수 있습니다. 복잡한 MAM 설계를 일목요연하게 정리해 주는 기능입니다.
- 역추적(Origin Finder): 목표 도형을 넣으면 어떤 중간 도형과 기계 조합이 필요한지 역으로 계산합니다. 긴 탐색은 별도 스레드에서 처리돼 UI가 멈추지 않습니다.
- 자동 분류: shape_classifier가 도형을 기본형, 하이브리드, 클로 등으로 나눠 어떤 공정이 적합한지 미리 알려 줍니다. 덕분에 MAM의 서브 모듈을 어떻게 구성할지 빠르게 판단할 수 있습니다.
- 정교한 검색 & 대량 처리: 정규식 검색과 Batch 탭으로 도형을 대량 정리하고, `Remove Impossible` 같은 도구로 불가능한 설계는 바로 걸러낼 수 있습니다.
- 로컬라이징 지원: locales 폴더에 있는 en.json·ko.json을 교체하면 UI 문구가 즉시 바뀝니다. 번역과 커뮤니티 협업이 쉬워, 자신만의 MAM 설계를 다국어로 공유하기 좋습니다.

## 이렇게 활용해 보세요

1. 도형 코드 입력: 게임에서 복사한 코드를 붙여넣고 기본 구조를 확인합니다.
2. 시뮬레이션 버튼 클릭: `Rotate 90`, `Stacker`, `Painter` 등 기계 버튼을 눌러 MAM의 세부 모듈을 시험합니다.
3. 역추적 실행: 완성형 도형을 Origin Finder에 넣어, 최소한의 공정으로 재현 가능한지 분석합니다.
4. 프로세스 트리 확인: `Generate Process Tree`로 전체 제작 과정을 그래프 형태로 조망하고, MAM 설계도에 반영합니다.
5. Batch 탭 정리: 여러 도형을 한꺼번에 처리해, MAM이 대응해야 할 패턴을 빠르게 확보합니다.

## 기술적으로 눈여겨볼 점

프로젝트는 Python 3.8+과 PyQt6를 사용합니다. `shape.py`가 도형의 기본 연산을, `data_operations.py`가 각종 변환을 담당합니다. 역추적 모듈은 QThread(OriginFinderThread)를 활용해 백그라운드에서 실행되므로, 무거운 분석도 GUI가 부드럽게 유지됩니다. QGraphicsView를 이용한 프로세스 트리 시각화, locale JSON 파일을 통한 즉시 번역 반영 등 커스텀이 쉬운 구조도 특징입니다.

## 다운로드와 참고 자료

개발자는 GitHub Releases에서 Windows용 실행 파일(Shapez2Analyzer.exe)을 제공합니다. README에는 튜토리얼 영상과 데모 GIF가 정리돼 있어 입문자가 접근하기 쉽습니다. 개발 환경에서 살펴보고 싶다면 `pip install -r requirements.txt` 후 `python gui.py`로 실행하면 됩니다. 다만, 예시 데이터와 기능 설명에는 게임 진행에 대한 스포일러가 포함되어 있으니 플레이 상황을 감안해서 사용하세요.

## 마치며

Shapez2 Analyzer는 “모든 도형을 맡길 수 있는 MAM”을 직접 설계하고 싶은 플레이어의 든든한 조력자입니다. 복잡한 공정을 한 번에 이해하고 싶은 분들, 커뮤니티에 효율적인 설계를 공유하고 싶은 분들에게 특히 추천합니다. 여러분의 공장이 한층 더 지능적으로 돌아가길 바랍니다!
