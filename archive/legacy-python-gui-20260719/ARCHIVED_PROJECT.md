# 레거시 프로젝트 아카이브

2026-07-19에 새 ZIP 기반 웹/데스크톱 프로젝트를 루트로 가져오기 전에 있던 Python GUI,
솔버, 데이터, 연구 스크립트, 빌드 산출물과 작업 중 변경사항을 이 디렉터리로 이동했다.

`.git` 디렉터리는 저장소 루트 유지를 위해 이동하지 않았다. `data/`는 외부 프로세스가
원본 하위 디렉터리를 점유해 이동 대신 먼저 복사했으며, 30개 파일과 총
14,978,248바이트가 원본과 일치함을 확인했다. 이후 루트 중복 파일은 제거했고, 외부
프로세스가 점유한 빈 `data/claw_stack_test` 디렉터리만 루트에 남을 수 있다.
